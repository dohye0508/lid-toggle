# lid-toggle

> 빌드 돌려놓고 자리를 떠야 하는데, 노트북을 닫으면 절전으로 들어가서 다 멈춰버리나요?

트레이 아이콘 하나로 **노트북 덮개 닫기 동작**을 켜고 끄는 작은 Windows 스크립트입니다. 설정 앱을 열고 전원 옵션으로 들어가서 "덮개를 닫을 때 수행할 작업"을 찾아 바꾸고 저장하는 그 과정을, 클릭 한 번으로 줄입니다.

학습이 끝날 때까지 닫아두고 싶을 때 켜고, 평소에는 다시 꺼두면 됩니다.

## 어떻게 생겼나

시계 옆 알림 영역(`^` 안쪽)에 동그란 아이콘이 하나 올라옵니다.

| 아이콘 | 상태 |
| --- | --- |
| 🟢 초록색 | 덮개를 닫아도 켜져 있음 |
| ⚪ 회색 | 덮개를 닫으면 절전 (Windows 기본값) |

- **왼쪽 클릭** — 두 상태를 전환하고 풍선 알림으로 알려줍니다
- **오른쪽 클릭** — 현재 상태에 체크 표시가 붙은 메뉴와 `종료`

전원 연결 중일 때와 배터리일 때를 함께 바꾸고, 지금 쓰고 있는 전원 구성표에 적용합니다. 구성표를 다른 데서 바꿔도 5초마다 다시 읽어서 아이콘 색이 따라옵니다.

## 쓰려면

1. 이 저장소를 받아서 아무 폴더에나 둡니다
2. `run-lid-tray.vbs` 를 더블클릭하면 트레이에 아이콘이 올라옵니다

검은 콘솔 창은 뜨지 않습니다. `.vbs` 래퍼가 PowerShell을 숨긴 채로 띄우기 때문입니다.

### 켤 때마다 자동으로

`install-startup.ps1` 을 우클릭해 `PowerShell에서 실행` 하면 시작프로그램 폴더에 바로가기를 넣어줍니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\install-startup.ps1
```

바로가기가 지금 폴더를 가리키므로, 등록한 뒤에는 폴더를 옮기지 마세요. 끄려면 `-Remove` 를 붙여 다시 실행하거나, `shell:startup` 폴더에서 바로가기를 지우면 됩니다.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `lid-tray.ps1` | 트레이 아이콘 본체 |
| `run-lid-tray.vbs` | 창을 숨긴 채 위 스크립트를 실행 |
| `install-startup.ps1` | 시작프로그램 등록 / 해제 (`-Remove`) |
| `toggle-lid.ps1` | 상주 없이 한 번 실행하면 전환되는 단순 버전 |

## 속사정

`powercfg` 로 전원 구성표의 덮개 설정을 바꿉니다. 해당하는 GUID는 이렇습니다.

```
하위 그룹  4f971e89-eebd-4455-a8de-9e59040e7347  (전원 단추 및 덮개)
설정       5ca83367-6e45-459f-a27b-476b1d01c936  (덮개 닫기 동작)
값         0 = 아무 것도 안 함   1 = 절전
```

현재 값은 레지스트리의 `HKLM\SYSTEM\CurrentControlSet\Control\Power\User\PowerSchemes` 아래에서 읽습니다. `powercfg /q` 로도 읽을 수 있지만 이 설정이 숨겨져 있는 환경에서는 아무것도 출력되지 않아, 레지스트리 쪽이 더 확실합니다.

관리자 권한은 필요 없습니다.

## 알아두면 좋은 것

덮개를 닫은 채로 오래 두면 열이 빠져나가지 못해 쌓입니다. 배터리로 장시간 돌릴 생각이라면 한 번 더 생각해보세요.

## 환경

Windows 11에서 Windows PowerShell 5.1로 만들고 확인했습니다. Windows 10에서도 같은 방식으로 동작할 것으로 보이지만 직접 확인하지는 않았습니다.
