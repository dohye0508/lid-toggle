# lid-toggle

> 빌드 돌려놓고 자리를 떠야 하는데, 노트북을 닫으면 절전으로 들어가서 다 멈춰버리나요?

설정 앱을 열고 전원 옵션으로 들어가서 "덮개를 닫을 때 수행할 작업"을 찾아 바꾸고 저장하는 그 과정을 클릭 한 번으로 줄입니다. 트레이 아이콘 하나로 **노트북 덮개 닫기 동작**을 켜고 끄는 작은 Windows 스크립트입니다.

학습이 끝날 때까지 닫아두고 싶을 때 켜고 평소에는 다시 꺼둡니다.

## 받기

[**최신 버전 내려받기**](https://github.com/dohye0508/lid-toggle/releases/latest). 릴리스 페이지에서 zip 파일을 받아 압축을 풀면 안에 `읽어보세요.txt` 가 있습니다. 그대로 따라가면 끝입니다. 설치 과정은 없습니다.

## 어떻게 생겼나

시계 옆 알림 영역(`^` 안쪽)에 동그란 아이콘이 하나 올라옵니다.

| 아이콘 | 상태 |
| --- | --- |
| 🟢 초록색 | 덮개를 닫아도 켜져 있음 |
| ⚪ 회색 | 덮개를 닫으면 절전 (Windows 기본값) |

- **왼쪽 클릭** — 두 상태를 전환하고 풍선 알림으로 알려줍니다
- **오른쪽 클릭** — 현재 상태에 체크 표시가 붙은 메뉴와 `종료`

전원 연결 중일 때와 배터리일 때를 함께 바꾸고 지금 쓰고 있는 전원 구성표에 적용합니다. 구성표를 다른 데서 바꿔도 5초마다 다시 읽으니 아이콘 색은 알아서 따라옵니다.

## 쓰려면

압축을 푼 폴더에서 `run-lid-tray.vbs` 를 더블클릭하세요. 트레이에 아이콘이 올라오는데 `.vbs` 래퍼가 PowerShell을 숨긴 채로 띄우기 때문에 검은 콘솔 창은 뜨지 않습니다.

인터넷에서 받은 파일이라 Windows가 한 번 경고할 수 있습니다. `추가 정보` → `실행` 으로 넘어가면 됩니다.

### 켤 때마다 자동으로

`시작프로그램 등록.bat` 을 더블클릭하세요. 되돌리려면 `시작프로그램 해제.bat` 입니다.

바로가기가 지금 폴더를 가리키므로 등록한 뒤에는 폴더를 옮기지 마세요. 이미 옮겼다면 등록을 다시 하면 됩니다.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `lid-tray.ps1` | 트레이 아이콘 본체 |
| `run-lid-tray.vbs` | 창을 숨긴 채 위 스크립트를 실행 |
| `시작프로그램 등록.bat` / `해제.bat` | 아래 스크립트를 더블클릭으로 실행 |
| `install-startup.ps1` | 시작프로그램 등록, `-Remove` 로 해제 |
| `toggle-lid.ps1` | 상주 없이 한 번 실행하면 전환되는 단순 버전 |

## 속사정

전원 구성표에는 덮개 설정이 들어 있고 이걸 `powercfg` 로 바꿉니다. 해당하는 GUID는 이렇습니다.

```
하위 그룹  4f971e89-eebd-4455-a8de-9e59040e7347  (전원 단추 및 덮개)
설정       5ca83367-6e45-459f-a27b-476b1d01c936  (덮개 닫기 동작)
값         0 = 아무 것도 안 함   1 = 절전
```

현재 값은 레지스트리의 `HKLM\SYSTEM\CurrentControlSet\Control\Power\User\PowerSchemes` 아래에서 읽습니다. `powercfg /q` 로도 읽을 수 있지만 이 설정이 숨겨져 있는 환경에서는 아무것도 출력되지 않아 레지스트리 쪽이 더 확실합니다.

관리자 권한은 필요 없습니다.

## 알아두면 좋은 것

덮개를 닫은 채로 오래 두면 열이 빠져나가지 못해 쌓입니다. 배터리로 장시간 돌릴 생각이라면 한 번 더 생각해보세요.

## 환경

Windows 11에서 Windows PowerShell 5.1로 만들고 확인했습니다. Windows 10에서도 같은 방식으로 동작할 것으로 보이지만 직접 확인하지는 않았습니다.
